# HIIT Builder

A small web app for building and running high intensity training sessions.

- Pick modules from a library of 38 exercises (bodyweight, light dumbbells, box or step, rack or pull-up bar), each with an animated demo, description and form cues.
- Set minutes per module, work/rest intervals or continuous, breaks, and how many rounds to repeat the list.
- Run the workout with a full-screen timer, beeps, and Pause / Back / Skip.

No build step and no dependencies: plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
node serve.js
```

Then open http://localhost:4173.
